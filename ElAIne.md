# ElAIne

ElAIne is a small, **local offline** diagnostic LLM scaffold for EA NI–style tech support (FOG, C2k, SIMS, Windows, printing, networking). It lives under **`ElAIne/`** and is **not** part of the WENDY ISO build, **`wendy-runtime/`**, or PXE artefacts.

See **`ElAIne/README.md`** for setup (**`Modelfile`**, **`scripts/build.sh`**, **`ingest.sh`**). Personal/internal use only; do not redistribute distilled Microsoft KB content against your org’s policies.

For how this fits with the rest of the repo, see **[Repository documentation](README.md#repository-documentation)** in **`README.md`** (same map linked from **`MetaRef.md`**, **`CursorRef.md`**, **`docs/architecture.md`**, and **`ROADMAP.md`**).
